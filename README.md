## 자료 구성

학교별 자료는 학교 폴더 아래에 독립적으로 정리합니다.
필요한 데이터의 출처·사용 조건, 패키지와 실행 방법은 각 폴더의 README를 참고하세요.
실제 QPU 사용 여부와 검증 범위도 각 실습에 별도로 표시합니다.

KMU 실습은 공개 BigSolDB 2.2의 물·25°C 부분집합을 가공한 교육 예제이며,
이상적인 광자 회로 시뮬레이션을 사용합니다.
원본 데이터는 [Krasnov et al., BigSolDB 2.2](https://doi.org/10.5281/zenodo.22648301),
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)입니다.
원저자·관련 논문·가공 내역은 [KMU/DATA_PROVENANCE.md](KMU/DATA_PROVENANCE.md)에 있습니다.
